## Monitoring and Logging

This project implements a Kubernetes-based monitoring and logging environment using Helm, Prometheus, Grafana and Loki.

The objective of this task is to deploy a monitoring stack, collect Kubernetes and system metrics, and configure a centralized logging component for application and cluster logs.

## Kubernetes Environment

The monitoring components were deployed inside a dedicated Kubernetes namespace.

Namespace: monitoring

The monitoring namespace contains the main components required for the monitoring stack.


---

## Helm Deployment

Helm was used to deploy the monitoring components into Kubernetes.

The Prometheus and Grafana stack was installed using the kube-prometheus-stack Helm chart.

Main components include:

- Prometheus

- Grafana

- Alertmanager

- Prometheus Operator

- kube-state-metrics

- Node Exporter



---

## Prometheus

Prometheus is responsible for collecting and storing time-series metrics.

The deployment provides monitoring information from the Kubernetes environment, including:

- Node metrics

- Pod metrics

- Container metrics

- Kubernetes object metrics

- Resource utilization


Prometheus was verified through Kubernetes pod and service status.


---

## Grafana

Grafana is used to visualize monitoring data collected by Prometheus.

The Grafana dashboard was accessed successfully and Prometheus metrics were queried through Grafana Explore.

Grafana provides a centralized interface for:

- Metrics visualization

- Dashboard monitoring

- Querying Prometheus data

- Exploring monitoring information



---

## Loki

Loki was deployed as the centralized logging component for the Kubernetes environment.

Loki is used to store and query log information generated by Kubernetes workloads.

The Loki deployment includes components required for log storage, querying and gateway access.

## Verification

The monitoring environment was verified using Kubernetes commands such as:

The main monitoring components reached a running state after deployment and troubleshooting.


---

## Troubleshooting Performed

During the deployment, several configuration and connectivity issues were encountered.

- Helm Installation

Helm was initially unavailable in the PowerShell environment.

The issue was resolved by installing/configuring Helm and verifying the installation before continuing with the Kubernetes deployment.

- Prometheus and Grafana

The kube-prometheus-stack deployment was verified by checking the status of the pods and services in the monitoring namespace.

- Grafana Metrics

Initially, Grafana Explore did not display metric data.

The Prometheus data source and metric selection were checked, after which monitoring data was successfully displayed.

- Loki Configuration

The initial Loki deployment encountered configuration issues related to storage configuration and deployment mode.

The Loki configuration was corrected and the required components were deployed successfully.

- Loki and Grafana Connectivity

The Loki service and gateway were checked from inside the Kubernetes environment.

The Grafana Loki data source was also tested during the configuration process.
